# Screenshot credits / 截图样片来源

All screenshots show the actual LUMEN RAW desktop application on Windows (DirectML). The interface is part of the MIT-licensed project. The visible photographs are CC0 test samples from [raw.pixls.us](https://raw.pixls.us/) and, in the 2.0.0 and 2.1.0 screenshots, Play Raw photographs from [discuss.pixls.us](https://discuss.pixls.us/c/raw-files/playraw/) under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) (listed below); the original RAW files are not included in this Git repository. The screenshots that show Play Raw photographs (`library-grid*.png`, `culling*.png`, `removal*`, `object-masks*.png`, `curve-ends*.png`) are shared under CC BY-SA 4.0 as well; in the 2.1.0 screenshots the photographs are edited (an object removed, a mask, a curve).

截图均为 LUMEN RAW 在 Windows 上的实际运行界面。`removal.png`、`object-masks.png`、`curve-ends.png`（中文）及对应的 `-en` 英文版为 2.1.0：「修复」面板中用「AI 移除 · 点选物体」单击灯塔后识别出的轮廓（紫色，正在补全）；`removal-before-after.jpg` 为同一张照片单击前（左）与单击后（右）的预览裁切；「蒙版」面板的风光蒙版按钮与「点选物体」，单击选中小猫；曝光曲线的黑点移到直方图开始处、白点正被拖到直方图结束处。这几张截图中的照片为 Play Raw 样片“Skagen Lighthouse”（wrjfoto）、“cute kitten between some plants”（bestman8）和 “Sunset and Dark Skies over Grand Canyon”（Laurent），经 LUMEN RAW 编辑（移除物体、蒙版、曲线），截图同样以 CC BY-SA 4.0 提供。`library-grid.png`（中文）和 `library-grid-en.png`（英文）为 2.0.0：导入 Play Raw 文件夹后的「图库」页，左侧为文件夹树、内置与一个自建的智能相册和关键词，网格中有星级、留用旗标、色标和被排除的照片，右侧为所选照片的信息、清晰度、评级与关键词（评级、关键词和智能相册为截图时设置）。`culling.png`（中文）和 `culling-en.png`（英文）为 2.0.0：选片的对比模式（截图时为窗口大小，平时全屏），左为选定的一张，右为琥珀色框中的候选，顶部为它的拍摄信息、评级与清晰度，下方为整组照片的胶片条。这两组截图中的照片来自 discuss.pixls.us 的 Play Raw，作者以 CC BY-SA 4.0 许可发布（作者与链接见上方英文列表），这两组截图同样以 CC BY-SA 4.0 提供。`presets.png`（中文）和 `presets-en.png`（英文）为 1.7.0：导入预设包后，「预设」面板按分组列出其中的 Lightroom 预设，已套用一个预设并载入一个 `.cube` LUT（强度 60%）；预设为仓库 `tests/presets` 中为 LUMEN RAW 编写的测试预设（MIT），英文截图中改了名字，LUT 为截图时生成。`fine-masks.jpg` 与 `fine-masks-en.jpg` 为 1.7.0：用 AI 天空蒙版压暗天空，左为 1.6 的快速蒙版，右为 1.7 的精细边缘，裁自 4096 像素的精细蒙版图像（尼康 D800 与索尼 RX100 VA 样片）。`tools.png` 与 `tools-en.png` 为 1.7.0：拖动直方图暗部区域时的显示，以及「调色」面板的吸管，高光色相由吸管从画面取得。`library.png`（中文）和 `library-en.png`（英文）为 1.6.0：底部图集的星级、留用旗标、排除（变暗）与色标，工具栏中的评级与筛选；状态栏显示 AI 助手通过控制通道完成的一步调整（截图时设置的提示文字）。`process2-sky.jpg` 与 `process2-highlights.jpg` 为同一组调整分别用处理版本 1（左）和 2（右）渲染。`lens.png`（中文）和 `workspace-en.png`（英文）为 1.5.1：「裁切·镜头」面板按 EXIF 识别出尼康 Z 14-24mm f/2.8 S（24 mm、f/8），并用 lensfun 配置文件校正畸变、暗角与横向色差。`workspace.png` 为 1.5.0：左侧是一次真实的自然语言修图，指令“暖一点，暗部提亮，颜色更鲜艳一些”由本机 LM Studio 运行的 qwen3-14b（关闭思考）返回参数。其余截图中的照片都来自 raw.pixls.us 的 CC0 公共测试样片；仓库不包含这些 RAW 原始文件。
