# Screenshot credits / 截图样片来源

截图均为 LUMEN RAW 在 Windows 上的实际运行界面。`presets.png`（中文）和 `presets-en.png`（英文）为 1.7.0：导入预设包后，「预设」面板按分组列出其中的 Lightroom 预设，已套用一个预设并载入一个 `.cube` LUT（强度 60%）；预设为仓库 `tests/presets` 中为 LUMEN RAW 编写的测试预设（MIT），英文截图中改了名字，LUT 为截图时生成。`fine-masks.jpg` 与 `fine-masks-en.jpg` 为 1.7.0：用 AI 天空蒙版压暗天空，左为 1.6 的快速蒙版，右为 1.7 的精细边缘，裁自 4096 像素的精细蒙版图像（尼康 D800 与索尼 RX100 VA 样片）。`tools.png` 与 `tools-en.png` 为 1.7.0：拖动直方图暗部区域时的显示，以及「调色」面板的吸管，高光色相由吸管从画面取得。`library.png`（中文）和 `library-en.png`（英文）为 1.6.0：底部图集的星级、留用旗标、排除（变暗）与色标，工具栏中的评级与筛选；状态栏显示 AI 助手通过控制通道完成的一步调整（截图时设置的提示文字）。`process2-sky.jpg` 与 `process2-highlights.jpg` 为同一组调整分别用处理版本 1（左）和 2（右）渲染。`lens.png`（中文）和 `workspace-en.png`（英文）为 1.5.1：「裁切·镜头」面板按 EXIF 识别出尼康 Z 14-24mm f/2.8 S（24 mm、f/8），并用 lensfun 配置文件校正畸变、暗角与横向色差。`workspace.png` 为 1.5.0：左侧是一次真实的自然语言修图，指令“暖一点，暗部提亮，颜色更鲜艳一些”由本机 LM Studio 运行的 qwen3-14b（关闭思考）返回参数。展示的照片都来自 raw.pixls.us 的 CC0 公共测试样片；仓库不包含这些 RAW 原始文件。
